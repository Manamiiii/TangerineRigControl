# 设备校准与验收清单

这份清单用于第一次连接实际灯光和屏幕。建议先单独测试每一项，确认后再使用“全部开启/全部关闭”。

## 1. 启动

1. 按 [README](../README.md#下载与运行) 下载、解压并运行预览包，或运行自行构建的 Release EXE。
2. 打开“设置与录制”，确认 L-Connect 3 和 KANALI 均显示正确的可执行文件。
3. 暂时不要勾选“Windows 登录时启动”，等单项测试完成后再启用。
4. 如果 KANALI 或 L-Connect 3 以管理员权限运行，请先退出控制台，再右键以管理员身份启动 TangerineRigControl。

## 2. 录制屏幕操作

每块屏幕分别录制“开启”和“关闭”：

1. 先在原厂软件中回到固定、可重复的起始页面。
2. 点击 TangerineRigControl 对应的“录制”按钮。
3. 把鼠标停在第一处需要点击的位置，按 `F8` 记录。
4. 手动点击该位置，等待页面稳定。
5. 对后续位置重复“按 F8 记录，然后手动点击”。
6. 最后点击录制窗口的“保存序列”。
7. 点击设置页“保存”，退出并重新打开设置页确认步骤仍存在。

录制开关前，先将它放在与目标相反的状态。请额外验证“开启 → 开启”和“关闭 → 关闭”；纯坐标开关可能只是切换状态，若第二次操作反转了设备状态，则该序列不能作为可靠的开启/关闭命令使用。

KANALI 内部确实有真正的 PANORAMA 屏幕启停选项，可以直接录制该开关，不需要创建纯黑素材。

录制时不要包含账号页面、图库文件名或其他可能变化的区域。操作序列只保存在本机 `%LOCALAPPDATA%`，不会提交到 GitHub。

## 3. 单项验证

按以下顺序测试：

1. TRYX 曲面屏关闭，然后开启。
2. 联力副屏关闭，然后开启。
   勾选“操作完成后最小化原厂软件”，确认每次成功执行后窗口收起，下一次操作能恢复实际页面并再次收起；取消勾选时窗口应保留。
3. 显卡灯光录制关闭/开启，然后验证主板＋内存 SDK 关闭/开启；选择华硕录制备用时才测试其录制。只录制灯光设置，不更改风扇转速。
4. 全部关闭，然后全部开启。
5. 将原厂软件缩到托盘，再重复一次屏幕测试。
   同时测试关闭原厂软件窗口但保留托盘进程后，点击“录制关闭”能否恢复主窗口；不应要求退出并重启原厂进程。
   L-Connect 必须看到实际页面内容，不能仅凭任务栏图标或窗口句柄判断已恢复。分别验证首次启动、普通最小化、关闭到托盘；恢复失败时应停止录制或回放并提示。
6. 在控制台隐藏时测试 `Ctrl + Alt + F10/F11/F12`。
7. 在等待步骤期间切换到其他窗口，确认序列停止，且没有点击其他窗口。
8. 测试主界面或托盘的“停止操作”，确认后续步骤不再执行；已完成的步骤不会撤销。
9. 录制一个草稿后取消设置页，确认原序列未改变；只有保存设置后才应生效。
10. 确认快捷键占用时显示注册失败提示；托盘提示应显示执行结果，而不是声称已确认屏幕状态。

每一步按保存的坐标点击并等待配置的步骤间隔。录制默认 900 毫秒，不记录手动等待时间；慢页面可在对应序列旁的“等待…”中调整前一步的等待，首次点击过早则调整“首次点击前等待”。应用到草稿后保存设置；原厂软件升级或布局变化后应重新验证。

代码自检不启动原厂软件、不发送鼠标点击，也不发送网络请求。它覆盖配置草稿隔离、旧配置字段兼容、非法配置拒绝、窗口保护、等待编辑取消和保存，以及旧配置迁移和四组序列的独立保存；不能代替以上硬件验证。

## 4. 出现问题时

优先记录以下内容：

- 控制台底部显示的错误文字。
- 哪个操作步骤发生偏移。
- 原厂软件当时是否最小化或以管理员身份运行。
- 控制台是否提示原厂软件与 TangerineRigControl 的权限不匹配。
- “设置与录制”中的“复制脱敏诊断”结果。

脱敏诊断不会包含用户名、安装路径、设备序列号或录制坐标。不要提交原厂软件日志，除非已经人工检查其中不含隐私信息。

## Aura SDK 验收

确认华硕默认灯效处于开启。先测试主板＋内存关闭、重复关闭、开启、重复开启；关闭后保持控制台运行，观察是否被 iGC.Lite 抢回。确认显卡与两块屏幕没有异常。再测试全部开关，确认显卡先执行，华硕最后执行。退出控制台会释放 SDK 并恢复默认灯效。取消设置页 SDK 选项后可使用保留的华硕录制。

本机 SDK 关灯调用及释放控制权调用已成功返回；硬件效果仍待用户观察验收。

## 质量修复后的必要复核

1. 从最终启动入口打开，确认两块屏幕的步骤仍存在；进入设置后取消，再进入，步数不变。
2. 分别验证未运行、普通最小化及隐藏到托盘的原厂窗口恢复。iGC 的启动器与实际窗口进程可能不同，本版本已单独匹配。
3. 检查全部操作按联力、TRYX、显卡、华硕顺序执行，主界面可滚动查看每项结果。
4. 原厂软件加载时点击停止，确认不会继续发出后续点击。SDK 超时提示“状态未知”时需在原厂软件确认灯效，不把停止等待当成底层调用已中断。
5. SDK 模式关闭后保持控制台运行，确认灯效；退出时确认恢复默认灯效符合预期。

损坏配置、备份保存、外部修改冲突和 SDK 卡住用测试夹具验证，不要求用户破坏真实配置或人为卡住设备。
